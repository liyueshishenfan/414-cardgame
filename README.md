# 414 · 传代

四人两队、异地联机的升级打牌游戏。手机、电脑浏览器都能玩，不需要装 App。

---

## 一、怎么开始

双击 **`start.bat`**。

它会自动：
1. 装依赖（第一次）
2. 开外网通道（如果装了 cloudflared）
3. 开游戏服务，并打开浏览器

---

## 二、四个人怎么连

### 方式 1：异地联机（固定地址，0 元）

**地址永远是这个，存成书签就行：**

```
https://414game.serveousercontent.com/?room=main
```

用法：

1. 双击 `start.bat`，它会同时开服务和隧道
2. 那个黑色的「邀请链接」窗口别关
3. 四个人都用浏览器打开上面这个地址，昵称随便起
4. 四人齐了自动开局

> 地址固定不变，隧道断了会自动重连，还是这个地址，刷新页面就能回来。
> 你的电脑关了，游戏就结束。

**注意**：这个地址走的是国外服务器，延迟约 500ms，能玩但不算流畅。
同 WiFi 请优先用方式 2。

### 方式 2：同一个 WiFi（最稳，不用装任何东西）

1. 双击 `start.bat`
2. 查自己电脑的局域网 IP（`ipconfig`，找 `192.168.x.x`）
3. 其他人访问 `http://192.168.x.x:3000`

### 方式 3：自己一个人测

同一浏览器开 **4 个标签页**，都访问同一个地址、同一个房间号。
（playerId 存在各标签页自己的 sessionStorage 里，互不干扰）

## 三、界面操作

| 操作 | 说明 |
|---|---|
| 点牌 | 选中 / 取消，选中的牌会抬起来 |
| 拖动牌 | 左右拖动可调整手牌顺序 |
| 整理 | 按点数重新排列 |
| 点大小王 | 弹出点数选择，选它变成哪张牌 |
| 出牌 | 打出选中的牌 |
| 不出 | 过牌 |
| 记录 | 查看对局日志 |

## 六、常见问题

**Q：提示"游戏已开始，无法加入"**
A：开局后不能中途加入。等这局打完，或重新开一个房间号。

**Q：外网链接打不开**
A：cloudflared 窗口关掉了，或者你的电脑休眠了。重新运行 `start.bat`。

**Q：手机打开是白屏**
A：确认手机和电脑连的是同一个链接，且电脑上的黑窗口还开着。

**Q：想改规则**
A：规则写在 `src/patterns.js`（牌型/大小）和 `src/room.js`（升级/结算）里，改完重启即可。改规则不花钱，只影响开发时间。
